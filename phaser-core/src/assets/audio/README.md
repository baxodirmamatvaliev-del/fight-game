# Optional audio replacements

No recordings ship with this project. Effects, two distinct placeholder grunt voices
and stage music are original Web Audio synthesis; announcer defaults use device
text-to-speech (voice availability varies). No Mortal Kombat samples are used.

Put your own licensed WAV recordings in **this folder** and restart Vite/rebuild.
The manager automatically discovers and decodes them. Missing or invalid files retain
the generated fallback. Speech captions remain available without speech support.
